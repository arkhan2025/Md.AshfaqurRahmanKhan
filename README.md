- **Showcase of 11 Web Projects:**

  - **Live Demo** button linking directly to verified production deployments

  - Category filters (*All Projects*, *Full Stack*, *Frontend*)

## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arkhan2025/Md.AshfaqurRahmanKhan.git
   cd Md.AshfaqurRahmanKhan
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
